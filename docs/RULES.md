## Prizes

Five winners, $500 + DEV++ membership + badge each. **Three from Path One, two from Path Two.**
Completion badge for every valid submission.

## Submission checklist

- [ ] DEV post using the official template for the chosen path
- [ ] Tags: `#sanitychallenge`, `#devchallenge`
- [ ] **Sanity project ID or public dataset URL in the post** — omission may render the
      submission incomplete. Most common disqualifier.
- [ ] Working demo link
- [ ] Login credentials if the app is gated
- [ ] Optional, high leverage: embedded agent session transcripts

## Path One — Ship an Agent That Queries Real Content

Agent connected to a **Context MCP endpoint backed by a Knowledge Base**.

Judged on: meaningful use of Sanity Context and structured content · technical implementation
and code quality · Knowledge Bases utilisation · usability.

## Path Two — Vibe-Code Something Strange

Next.js **or** Astro frontend, Sanity backend, built with an AI-native IDE.

Judged on: quality and **honesty** of build-process documentation · app functionality ·
schema thoughtfulness · creativity and originality.

**Bonus points for App SDK or Workflows.** DRIFT uses both.

## Tiebreaker

Highest DEV post reactions. Then: favour entrants without a prior win.

→ Ship at least 48 hours early so reactions have time to accumulate.
